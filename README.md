# Bill Splitter & Tip Calculator

A simple, light-themed web application to calculate tips and split bills dynamically among friends. Built using basic HTML, CSS, and vanilla JavaScript.

## Features

- **Dynamic Calculations**: Computes tip amount per person and total bill per person instantly.
- **Input Validation**: Displays a simple error message if the number of people is set to 0 or left empty.
- **Clean UI**: Simple light theme card layout.
- **Responsive Design**: Works perfectly on both desktop and mobile browsers.

## Project Structure

```text
├── index.html   # Main HTML markup
├── style.css    # Clean styling and card layout
├── script.js    # Calculation logic and DOM manipulation
└── README.md    # Project documentation
```

## How to Run

1. Clone or download this repository.
2. Open `index.html` directly in any web browser.
3. Enter the total bill amount, tip percentage, and number of people to calculate.
